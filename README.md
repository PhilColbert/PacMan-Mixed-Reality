# Pac-Man Mixed Reality

Meta Quest 3 mixed-reality Pac-Man-inspired game targeting a human-scale 20m × 20m play area.

## Current development status — v0.5
A Unity 6.3 project foundation is present on the `hpac-chg-005-unity6-project-foundation` branch. It includes project metadata, XR/OpenXR package declarations and an Editor utility to generate a prototype preview scene. It is not yet a compiled or Quest-ready build.

## Open in Unity
Open this repository root in Unity Hub using Unity 6.3 LTS. See [Unity 6.3 setup](Unity/UNITY_6_SETUP.md), then run **Tools > HPAC > Generate Prototype Scene**.
