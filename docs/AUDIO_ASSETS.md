## Licensing position
Original Pac-Man soundtrack and game effects are protected franchise/game audio. Bandai Namco provides a licensing enquiry route for PAC-MAN: https://www.bandainamcoent.com/licensing. Its official music catalogue lists PAC-MAN game sound effect soundtrack releases, but listing/streaming a track does not grant reuse rights in this game.

## Integration rules
- Only use assets after confirming the actual downloaded package contains the claimed licence/readme.
- Keep original files unchanged; log filenames, SHA-256 hashes, author, source URL, licence and any attribution requirements.
- Convert/compress copies for Unity only; keep source masters.
- Do not use ripped audio from ROMs, YouTube or game recordings.
